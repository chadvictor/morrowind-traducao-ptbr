# Morrowind PT-BR 0.1.0-beta.2 — mod pronto para OpenMW

**Para jogar, baixe `morrowind-ptbr-openmw-mod-0.1.0-beta.2.zip`. Não precisa de Python.**

Extraia o ZIP, adicione sua pasta `Data Files` ao OpenMW Launcher e marque `Morrowind_PTBR.esp` depois de Morrowind, Tribunal e Bloodmoon. Requer jogo GOTY em inglês adquirido pelo usuário e OpenMW 0.51.0; testado no Windows com a edição Steam. Comece um jogo novo.

[Guia de instalação e ajustes de interface](https://github.com/chadvictor/morrowind-traducao-ptbr/blob/main/docs/INSTALACAO.md)

O pacote inclui plugin ESP, mapas, menus e recursos traduzidos. Ajuste `preferred locales` e os fallbacks conforme o guia para completar a interface; launcher/assistente Qt são extras opcionais. Não inclui masters completos, BSA, dublagem, filmes ou executáveis comerciais.

O ZIP `morrowind-ptbr-fontes-python-0.1.0-beta.2.zip` é uma opção avançada com fontes, validação e reconstrução local. Jogadores não precisam baixá-lo. Os downloads automáticos “Source code” do GitHub também são fontes, não o mod pronto.

**Quem usava a beta.1 deve desativar a instalação antiga antes.** Não combine masters traduzidos com o ESP; não há migração validada de saves.

Validação: comparação do estado efetivo dos registros e dos 31.822 INFOs, leitura pelo `esmtool`, 3.223 verificações no OpenMW e 15.570/15.570 scripts de diálogo compilados. O erro preexistente de `Museum` continua igual ao original. Há 17 testes automatizados das ferramentas, sem arquivos comerciais na CI.

Continua sendo uma **beta comunitária**, com tradução inicial auxiliada por IA, sem revisão humana integral ou campanha completa testada. O texto é o mesmo da beta.1. Mods de diálogo/scripts precisam de avaliação. Contribuições e relatos de problemas são bem-vindos.
